# 要件定義: 画像 / 動画生成ツール

- ステータス: approved
- 作成日: 2026-09-17
- 更新日: 2026-09-17

## 1. 背景 / 課題

現状のエージェントはテキスト応答しか返せない。ユーザーが「〜の画像を作って」と依頼しても応えられない。
ADK のツール(Function Calling)としてメディア生成を持たせ、エージェントが自分で判断して呼べるようにする。

## 2. ゴール / 非ゴール

### ゴール
- ユーザーが**画像生成を望んだ場合**、エージェントが画像生成ツールを呼んで画像を生成する。
- 生成した画像を `backend/app/created_images/` に保存し、保存先をユーザーに伝える。
- 同様に動画も生成できる。
- 使用モデルは設定で変更できる(既定は画像 `gemini-3.1-flash-lite-image` / 動画 `gemini-omni-1.1-flash-preview`)。

### 非ゴール
- 生成した画像・動画を HTTP API のレスポンスとして返すこと(保存先パスを返すのみ)。
- フロントエンドでの画像表示。
- 既存画像の編集(image-to-image)、参照画像を与えた生成。
- 生成物の世代管理・削除。

## 3. ユーザーストーリー

- 利用者として、「青空の写真を作って」と頼むだけで画像を生成してほしい。ツール名や API を意識したくないため。
- 開発者として、生成物がローカルに保存され、すぐ開いて確認できるようにしたい。

## 4. 受け入れ基準

- [x] AC-1: Given CLI, When 「〜の画像を作って」と依頼, Then 画像が生成され `backend/app/created_images/` に保存される。
- [x] AC-2: Given 画像生成後, When 応答を見る, Then 保存されたファイル名(またはパス)が案内される。
- [x] AC-3: Given 「〜の動画を作って」と依頼, When 実行, Then 動画が生成され保存される。
- [x] AC-4: Given 画像生成が不要な質問(例: 「1+1は?」), When 実行, Then ツールは呼ばれずテキストで応答する。
- [x] AC-5: Given 生成に失敗した場合, When 実行, Then 例外で落ちず、失敗した旨が応答に含まれる。
- [x] AC-6: Given `uv run python -m pytest`, When 実行, Then 外部 API を呼ばずにテストが通る。

## 5. 制約 / 前提

- 画像生成は `generateContent`(`response_modalities=["TEXT","IMAGE"]`)でインライン画像が返る。
- **動画生成は Interactions API 専用**。`generateContent` では 400 になるため `client.interactions.create()` を使う。
  結果は `output_video.data`(base64)で返る。生成には数十秒かかる。
- 認証は ADC(spec 001 と同じ)。
- 保存ディレクトリは Git 管理外にする(生成物をコミットしない)。
