# 要件定義: YouTube の MV からメタ情報を取得する

- ステータス: done
- 作成日: 2026-09-29
- 更新日: 2026-09-29

## 1. 背景 / 課題

アーティストの公演情報を Gemini に調べさせたい(後続の spec で扱う)。
調査の精度は**渡すアーティスト名の正確さ**に左右されるが、利用者が手で入力すると表記ゆれや誤字が起きる。
利用者が普段見ている **MV(YouTube の動画)を起点に**、YouTube Data API からアーティスト名・曲名などを取得できれば、
正確な情報を少ない手間で揃えられる。

## 2. ゴール / 非ゴール

### ゴール
- Web アプリの入力 UI に **YouTube の URL** または **MV 名**を入力できる。
  どちらから入力しても、最終的に **リンク(URL)・MV 名・アーティスト名**が揃う。
- URL の場合は、その動画のメタ情報(MV 名・アーティスト名など)を取得して表示する。
- MV 名の場合は、YouTube を検索して候補を表示し、利用者が選んだ動画の**リンク**とメタ情報を表示する。
- 動画タイトルがよくあるパターン(例: `アーティスト - 曲名`)なら、**アーティスト名と曲名に分解**する。
  当てはまらない場合は YouTube API の値(チャンネル名・動画タイトル)をそのまま使う。
- 取得結果は、後続の公演情報の調査に**そのまま渡せる形**(1 つのデータ構造)にする。

### 取得する項目

| 項目 | 取得元 | 用途 |
| --- | --- | --- |
| 動画 ID / URL | 入力 または 検索結果 | 動画の識別・リンク |
| アーティスト名 | タイトルの分解。できなければチャンネル名 | 公演情報の調査 |
| 曲名(MV 名) | タイトルの分解。できなければ動画タイトル | 表示・調査の補助 |
| 分解できたか | 分解処理の結果 | 後続の処理がアーティスト名の確からしさを判断する |
| 動画タイトル(元の値) | YouTube API | 表示・調査の補助 |
| チャンネル名(元の値) | YouTube API | 表示・調査の補助 |
| 公開日 | YouTube API | 調査の補助(活動時期の手がかり) |
| サムネイル URL | YouTube API | 候補一覧・結果の表示 |
| 概要欄 | YouTube API | 調査の補助(ツアー告知が載っていることがある) |

タグ・再生時間・再生回数は取得しない(公演情報の調査に使わないため)。

### 非ゴール
- 公演情報の調査そのもの(Gemini への問い合わせ)。公演名・日付の入力も含めて後続の spec で扱う。
- Gemini によるアーティスト名・曲名の推定(今回はルールによる分解のみ)。
- 公式 MV かどうかの判定(歌ってみた・切り抜きなどの除外)。
- 再生リスト・チャンネルの URL の入力(対象は動画 1 本の URL のみ)。
- 取得結果の保存(履歴・DB)。
- アプリ内での動画の再生(サムネイルの表示まで)。
- エージェントのツールとしての提供(チャットからの利用)。

## 3. ユーザーストーリー

- 利用者として、好きな MV の URL を貼るだけでアーティスト名と曲名を確認したい。手入力は面倒で間違えやすいから。
- 利用者として、URL が手元になくても MV 名で探し、その MV のリンクを得たい。
- 開発者として、公演情報を調べる機能に確かなアーティスト名を渡したい。Gemini の調査精度が上がるから。

## 5. 制約 / 前提

- YouTube Data API v3 を使う(ページのスクレイピングはしない)。
  MV 名からリンクを得るには YouTube 上の検索が必要で、oEmbed(キー不要)では検索できないため。
  Gemini + Google 検索でも URL は得られるが、実在しない動画 ID を返すことがあるため採用しない。
- クォータ: 既定の上限は 1 日 10,000 ユニット。動画情報の取得は 1 回 1 ユニットだが、**検索は 1 回 100 ユニット**(= 1 日およそ 100 回)。
  入力中に検索を繰り返す(インクリメンタル検索)などの、検索回数が増える作りにはしない。
- 認証は **API キー**(`backend/.env` の `YOUTUBE_DATA_API_KEY`)。YouTube Data API は、Gemini で使っている ADC の既定スコープ(`cloud-platform`)では呼べないため、README の「キーを `.env` に置かない」方針の例外とする。
- 新しい公開 API を追加する。既存の `/api/v1/chat` は変更しない。
- YouTube API の呼び出しは `app/services/` に閉じ、テストではスタブにする。
- 依存する spec: [000-local-dev-environment](../000-local-dev-environment/)、[001-gemini-adk-chat](../001-gemini-adk-chat/)(ADC の認証方針)
