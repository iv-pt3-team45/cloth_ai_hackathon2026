# 要件定義: 服インデックスをエージェントから参照する

- ステータス: approved
- 作成日: 2026-09-17
- 更新日: 2026-09-17

## 1. 背景 / 課題

spec 005 で服の属性インデックス(`index.json`)を作れるようになったが、エージェントはこれを見られない。
「手持ちの服でコーデを考えて」のような依頼に答えるには、**必要に応じてインデックスを参照できる**必要がある。

## 2. ゴール / 非ゴール

### ゴール
- `run_agent.py`(対話)と `run_agent_loop.py`(ループ)の両方で、エージェントがインデックスを参照できる。
- **必要なときだけ参照する**(インデックスと無関係な質問では読み込まない)。
- 参照先のインデックスは設定と CLI オプションで差し替えられる。
- インデックスが無い場合もエラーで落ちず、その旨を答える。

### 非ゴール
- インデックスの更新・追記(作成は spec 005 の CLI が担当)。
- 画像そのものをエージェントに渡すこと(属性テキストのみを渡す)。
- ベクトル検索・類似度検索(件数が少ないためキーワード一致で足りる)。

## 3. ユーザーストーリー

- 利用者として、「手持ちの白いTシャツに合うボトムスは?」と聞けば、自分の服を踏まえて答えてほしい。
- 利用者として、服と関係ない質問のときは余計な情報を読まないでほしい。

## 4. 受け入れ基準

- [x] AC-1: Given インデックスがある状態, When 「手持ちの服を教えて」と依頼, Then 登録済みの服が一覧で答えられる。
- [x] AC-2: Given インデックスがある状態, When 「デニムに合う服は?」と依頼, Then 該当する服を検索して踏まえた回答になる。
- [x] AC-3: Given 服と無関係な質問, When 実行, Then インデックス参照ツールは呼ばれない。
- [x] AC-4: Given インデックスが無い状態, When 服について依頼, Then 落ちずに「インデックスが無い」と分かる応答になる。
- [x] AC-5: Given `--index <パス>`, When 実行, Then 指定したインデックスが参照される。
- [x] AC-6: Given `uv run python -m pytest`, When 実行, Then 外部 API を呼ばずに検索処理を検証できる。

## 5. 制約 / 前提

- インデックスは spec 005 の形式(`index.json`)。
- エージェントに渡すのは属性テキストのみ(画像は渡さない)。
