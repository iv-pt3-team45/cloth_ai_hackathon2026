# 設計: プライバシーポリシーの画面

- 対応する要件: `./requirements.md`
- ステータス: approved
- 更新日: 2026-10-13(サービス名や期間などの具体的な値を書かない。4.2。spec 038〜041 の取り込みに合わせて 2・4.2・4.3 を更新)

## 1. 設計方針

| 案 | 内容 | 採否 | 理由 |
| --- | --- | --- | --- |
| A | ポリシーの文を Dart のデータ(節の一覧)として持ち、アプリ内の画面で `SectionCard` に並べる。`pushThemed`(spec 041。中身は `Navigator.push`)で開く | 採用 | 依存の追加なし。今のデザイン(spec 015)の部品がそのまま使える。テストで文の中身を確かめられる |
| B | Markdown のアセットを読み込んで表示する | 却下 | Markdown の表示に依存(`flutter_markdown` など)の追加が要る |
| C | `web/privacy.html` を置いて新しいタブで開く | 却下 | 要件の非ゴール(別の Web ページ)。デザインを HTML で別に作る必要がある |

画面の切り替えは `pushThemed`(入力の画面の配色を引き継いで `Navigator.push` する。spec 041)にする。初期ページの `HomePage` は下に残るため、戻ったときに入力の状態がそのまま残る(AC-3)。
ブラウザの戻るは、Flutter Web が `Navigator` の 1 つ前に戻す(テストではシステムの戻る `handlePopRoute` で確かめる)。

## 2. 画面

### 2.1 初期ページのリンク

```
┌ ③ 手持ちの服 ───────────────┐
│ …                             │
└───────────────────────────────┘
          プライバシーポリシー          ← 中央・12px・背景用の薄い文字色・下線
┌ [提案ボタンのバー(固定)] ─────┐
```

- 入力の段階のカードの並び(`Visibility(visible: _phase == Phase.input)` の中)の最後、③ のカードの下に置く。
  AI が考え中・提案の段階では出ない(AC-5)。
- スクロールする本文の中に置くため、画面下に固定の提案ボタンのバー(`bottomNavigationBar`)に隠れない(AC-1)。
- `TextButton`(文字は 12px・下線)。色は `AppPalette.of(context).onBackgroundMuted`(標準の配色では灰色 `AppColors.muted`、MV に合わせた暗い背景では明るい色。カードの外の文字の決まり。spec 041)。押せる範囲は高さ 40px 以上を取る。キー `privacyPolicyLinkKey`。
- 置き場所は `_buildBody` の入力の段階の並びの最後(③ の `WardrobeSection` の下)。

### 2.2 プライバシーポリシーの画面

- `PaletteBackground`(入力の画面と同じ背景のグラデーション)+ 透明の `Scaffold` + `AppBar`(題「プライバシーポリシー」、← で戻る。文字は背景用の色 `onBackground`)。ログインの画面(spec 040 の `AuthScaffold`)と同じ作り。
- 本文は幅 880px までで中央に置く(初期ページと同じ)。
- **全文を 1 つの白い枠(`SectionCard` 1 つ)にまとめる**(2026-10-13 ユーザー決定。節ごとに枠を分けない)。
  枠の中は、前置きの文と制定日 → 節ごとに太字の見出し「1. はじめに」→ 前置きの文 → 箇条書き(`Bullets`)→ 補足の文の順。

## 5. エラーハンドリング / 非機能

- 通信をしないため、エラーの表示は無い。
- 文字の大きさはテーマに従う(本文は通常の大きさ、リンクだけ 12px)。リンクは読み上げで「プライバシーポリシー」ボタンとして読まれる。
- データの扱い(保存先・見られる人・保存期間・外部のサービス)を変える spec は、同じ変更で `privacy_policy.dart` も直す(README に書く)。
  spec 038(ログイン)〜041 は取り込み済みで、2・3・5・6・8・9 をそれらの動きに合わせてある。

## 6. テスト方針

| 対象 | 手段 | AC |
| --- | --- | --- |
| リンクの位置 | 初期ページ(スマホの幅 390×844)で一番下までスクロールし、リンクが本文の中にあり押せる(提案ボタンのバーに隠れない) | AC-1 |
| 画面を開く | リンクを押すとポリシーの画面が開き、1 つの枠の中に 11 の節の見出し(「1. はじめに」など)と、見られる人(本人だけ)・運営者の名前が出る | AC-2 |
| 戻る | ← とシステムの戻る(`handlePopRoute`)で初期ページに戻り、① に入力した文字が残っている | AC-3 |
| 内容 | `policySections` が 11 節で、要点(外部のサービスに送る・本人だけが見られる・ゲストは自動で消える・ログインの情報・新規登録は送らない・削除後もしばらく復元できる・解析と広告なし・アプリ名)を含み、サービスの名前や日数(Google・YouTube・1 日・7 日など)と前のアプリ名を含まない | AC-4 |
| 段階 | AI が考え中・提案の段階ではリンクが出ない | AC-5 |

`dart format .` / `flutter analyze` / `flutter test` を通す(AC-6)。バックエンドは変えないため pytest は対象外。
