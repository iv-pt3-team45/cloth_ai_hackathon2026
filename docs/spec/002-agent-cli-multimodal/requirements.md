# 要件定義: エージェント単体実行 CLI とマルチモーダル入力

- ステータス: approved
- 作成日: 2026-09-17
- 更新日: 2026-09-17

## 1. 背景 / 課題

現状エージェントを試すにはサーバを起動して HTTP で叩く必要があり、プロンプトやツールの試行錯誤が重い。
また入力がテキストのみで、画像・動画を扱えない。

## 2. ゴール / 非ゴール

### ゴール
- **py ファイルを実行するだけでエージェントを動かせる**(フロント・サーバ不要)。対話形式で連続して会話できる。
- エージェントに**画像・動画を渡せる**。ローカルファイルと Cloud Storage(`gs://`)の両方に対応する。
- 同じ入力方式を HTTP API(`POST /api/v1/chat`)でも使えるようにする(既存の呼び出しは壊さない)。

### 非ゴール
- 会話履歴への添付ファイルの保持(添付は「今回のメッセージ」に対してのみ)。
- ファイルのアップロード API(バックエンドが受け取るのは base64 か URI)。
- 音声・PDF 等の対応(実装上は同じ経路だが、動作確認の対象外)。

## 3. ユーザーストーリー

- 開発者として、プロンプトやツールの調整をターミナルだけで素早く試したい。サーバ起動とフロント操作を挟みたくないため。
- 開発者として、手元の画像や動画をエージェントに渡して応答を確認したい。マルチモーダル機能を検証するため。

## 4. 受け入れ基準

- [x] AC-1: Given `backend/`, When `uv run python scripts/run_agent.py`, Then 対話プロンプトが起動し、入力した質問に応答が返る。
- [x] AC-2: Given 対話中, When `/file <パス>` で画像を添付して質問, Then 画像の内容を踏まえた応答が返る。
- [x] AC-3: Given `-m "質問" -f <パス>`, When 実行, Then 1 回だけ実行して結果を出力し終了する(非対話)。
- [x] AC-4: Given `gs://` で始まる URI, When 添付, Then ダウンロードせず URI のまま Gemini に渡る。
- [x] AC-5: Given `POST /api/v1/chat` の `attachments`, When 画像を base64 で送信, Then 同じ結果が得られる。既存の `attachments` 無しリクエストは従来どおり動く。
- [x] AC-6: Given 対応外の拡張子 / 存在しないファイル, When 添付, Then 分かりやすいエラーになり、対話は継続する。

## 5. 制約 / 前提

- インライン(base64)で送れるサイズにはリクエスト上限がある。大きい動画は `gs://` を使う。
- 認証は ADC(spec 001 と同じ)。CLI も同じ `AgentService` を使う。
