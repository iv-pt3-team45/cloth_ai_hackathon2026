# 要件定義: ライブ情報の検索と、MV 候補のその場での展開

- ステータス: approved
- 作成日: 2026-09-29
- 更新日: 2026-09-29

## 1. 背景 / 課題

spec 007 / 008 で、MV からアーティスト名とカルチャー情報(ファッション・経歴・MV の衣装)が揃うようになった。
最終的には「行くライブに合わせたコーデ」を手持ちの服で提案したい(後続の spec)。そのためには
**どのライブに行くのか(ライブ名・場所・日付)と、当日の天気**が必要になる。天気は服装(上着・雨具など)を大きく左右する。

また現状は、MV の候補を選ぶと候補一覧が消えて詳細に切り替わるため、候補を見比べにくい。
候補一覧を残したまま、選んだ候補の下に情報を広げたい。

## 2. ゴール / 非ゴール

### ゴール

**A. MV 候補のその場での展開(spec 007 / 008 の画面の変更)**
- 候補を選んでも画面は切り替わらず、**選んだ候補の直下に**動画情報とカルチャー情報を展開する。候補一覧はそのまま残る。
- 別の候補を選ぶと、前の展開は閉じて新しい候補の下に展開する。展開中の候補をもう一度押すと閉じる。
- 「候補一覧に戻る」ボタンは不要になるため廃止する。URL を入力した場合(候補が無い)の表示は今のまま。

**B. ライブ情報の検索(新機能)**
- MV 検索ページに、**ライブ情報(ライブ名・ツアー名・会場などのキーワード)と日付**の入力欄を追加する。**どちらか一方**があれば検索できる。
- バックエンドは Gemini + **Google 検索(グラウンディング)**で該当するライブを調べ、候補を**最大 3 件**提示する。
- 表示中の動画(spec 007 / 008)で**アーティストが分かっている場合は、そのアーティストのライブとして調べ、アーティスト名は取得しない**。
  分かっていない場合(動画を表示していない場合)は、Gemini が入力からアーティストを特定し、候補ごとにアーティスト名を取得する。
- 利用者は 3 件の候補から**1 件を選べる**。選んだ候補は強調表示する(後続のコーデ提案で使う前提。保存はしない)。
- 出典と Google の検索候補を表示する(Grounding with Google Search の利用条件。spec 008 と同じ)。

### ライブ候補ごとに取得する項目

| 項目 | 内容 | 例 |
| --- | --- | --- |
| アーティスト名 | **表示中の動画でアーティストが分かっている場合は取得しない** | YOASOBI |
| ライブ名 | ツアー名・公演名 | YOASOBI ARENA TOUR 2023 "電光石火" |
| 場所 | 会場名と所在地(都道府県・市区町村) | さいたまスーパーアリーナ(埼玉県さいたま市) |
| 日付 | 公演日(1 候補 = 1 公演日) | 2023-06-04 |
| 当日の天気 | 天気の概況・最高 / 最低気温・降水確率(分かる範囲)。**実績か予報か**も示す | 晴れ時々曇り / 最高 27℃・最低 18℃(実績) |

- 天気は、過去の公演なら**実際の天気**、先の公演で予報が出ていれば**予報**、予報がまだ出ていなければ「予報はまだありません」とする。
  分からない値は推測で埋めない(「不明」)。

### 非ゴール
- コーデ提案そのもの(後続の spec)。選んだライブを渡す仕組みも後続の spec で扱う。
- チケット情報・セットリスト・出演者の詳細。
- 天気 API の利用(天気も Gemini + Google 検索で調べる)。天気の数値の正確さの保証。
- 結果・選んだライブの保存(Google 検索のグラウンディング結果は保存しない方針。spec 008 と同じ)。
- 1 つの候補に複数の公演日をまとめること(ツアーの各日程は別の候補になる)。

## 3. ユーザーストーリー

- 利用者として、行く(行った)ライブの名前か日付を入れるだけで、会場・日程・当日の天気を知りたい。服装を決める材料にしたいから。
- 利用者として、MV で調べたアーティストのライブなら、アーティスト名を入れ直したくない。
- 利用者として、候補の中から自分が行くライブを選んでおきたい。
- 利用者として、MV の候補を選んでも一覧が消えないでほしい。他の候補と見比べたいから。

## 4. 受け入れ基準

未チェックの AC(画面の表示・操作)は、自動テスト(フェイクの Repository)と実 API(tasks.md の T-09)では確認済み。
ブラウザでの目視確認(T-10)が済んだらチェックする。

### A. MV 候補のその場での展開

- [ ] AC-1: Given MV 名で検索した候補一覧, When 候補を選ぶ, Then 画面は切り替わらず、その候補の直下に動画情報とカルチャー情報が展開され、候補一覧は残る。
- [ ] AC-2: Given 候補を 1 件展開している, When 別の候補を選ぶ, Then 前の展開は閉じ、選んだ候補の直下に展開されて、カルチャー情報を取得し直す(使い回さない)。
- [ ] AC-3: Given 候補を展開している, When その候補をもう一度押す, Then 展開が閉じる。
- [ ] AC-4: Given カルチャー情報の取得中, When 他の候補を押す, Then 反応しない(spec 008 AC-2 の方針を引き継ぐ)。

### B. ライブ情報の検索

- [ ] AC-5: Given ライブ情報と日付のどちらか一方以上を入力, When 検索する, Then Gemini が該当するライブを調べ、最大 3 件の候補が表示される。
- [x] AC-6: Given ライブ情報も日付も空, When 検索する, Then 入力エラーが表示され、API は呼ばれない。
- [x] AC-7: Given 表示中の動画でアーティストが分かっている, When 検索する, Then そのアーティストのライブとして調べられ、候補ごとのアーティスト名は取得されない(表示中のアーティストとして示される)。
- [ ] AC-8: Given 動画を表示していない, When 検索する, Then 候補ごとにアーティスト名が表示される。
- [ ] AC-9: Given 検索が完了した, When 画面を見る, Then 各候補にライブ名・場所・日付・当日の天気が表示される。
- [x] AC-10: Given 過去の公演 / 予報が出ている先の公演 / 予報がまだ出ていない先の公演, When 検索する, Then 天気はそれぞれ「実績」/「予報」/「予報はまだありません」として表示され、分からない値は「不明」になる。
- [ ] AC-11: Given 検索が完了した, When 画面を見る, Then 出典(タイトル・URL)と Google の検索候補が表示される。
- [ ] AC-12: Given 候補が表示されている, When 1 件を選ぶ, Then その候補が強調表示される。別の候補を選ぶと選択が移る。
- [x] AC-13: Given 該当するライブが見つからない, When 検索する, Then 「見つからなかった」旨が表示される。
- [ ] AC-14: Given ライブ情報の検索中, When 画面を見る / 操作する, Then ローディング表示が出て、MV 検索ページの他の入力(MV の検索・候補の選択・ライブの再検索)を受け付けない。カルチャー情報の取得中も、ライブの検索は受け付けない。
- [x] AC-15: Given Gemini または検索の失敗(クォータ超過・タイムアウトなど), When 検索する, Then エラーと再試行ボタンが表示される。
- [x] AC-16: Given `uv run python -m pytest` と `flutter test`, When 実行, Then Gemini を呼ばずに、入力の検証・結果の解釈・エラーの変換・画面の状態の切り替えを検証できる。

## 5. 制約 / 前提

- Gemini は Vertex AI 経由(ADC)。**Grounding with Google Search** を使い、spec 008 と同じく「調べる(検索あり・自由文)→ 整理する(検索なし・JSON)」の 2 段階で呼ぶ。
- 検索候補(Search Suggestions)の表示が必須、結果は保存しない(spec 008 の決定を引き継ぐ)。検索するたびにグラウンディングの料金がかかる。
- 天気の予報が出るのはおよそ 2 週間先まで。それより先の公演は「予報はまだありません」になる。
- 日付は日本時間として扱う。
- 表示中のアーティストは、spec 008 で Gemini が特定したアーティスト名を優先し、無ければ spec 007 の分解結果(分解できた場合のみ)を使う。
- 外部 API(Gemini)の呼び出しは `app/services/` に閉じ、テストではスタブにする。
- 依存する spec: [007-youtube-mv-metadata](../007-youtube-mv-metadata/)、[008-artist-culture-info](../008-artist-culture-info/)。
